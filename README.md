# Daily Activities

Two small phone-friendly web apps, each in its own folder.

- **Art of War Daily** (`artofwar/`): a daily reading page for Sun Tzu's *The Art of War*. One theme a day, with modern applications and follow-up questions. Live at https://tjhowlett.github.io/Daily-Activities/artofwar/
- **Daily Quiz** (`quiz/`): a 10-question multiple-choice quiz for learning new things, with source links for each question. Live at https://tjhowlett.github.io/Daily-Activities/quiz/

These two apps replace the old stand-alone `artofwar` and `quiz` repos, which are now archived.
